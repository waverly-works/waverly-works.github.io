02. Component Build

Understanding Zero State

DEFINITION

A customizable series of components used to represent empty states

EXAMPLE

If there are no items available for a specific folder, Zero State will demonstrate this

UNDERSTANDING COMPONENTS:

📌 What variants are needed for each Zero State usage case

📌 The different ways to create a component in Figma

Multiple Ways of Making

FIRST ATTEMPT:

My first attempt of creating the component had me making 18 separate variants for each usage case

FINAL VERSION:

After review with Anna, I consolidated the 18 variants into three, with different properties for each (see video below)

COMPONENT TAKEAWAYS:

📌 There isn't a wrong or right way to make a component

📌 My first attempt is successful in terms of having all the possible variants laid out in one space

📌 The final version is successful in terms of having the three main states laid out and smaller customizations for each

03. Component Specs

Building Specifications

Why Build Specs?

Having a page with an explicit, detailed layout of the component helps developers quickly understand how to build it out

BUILDING OUT COMPONENT SPECS:

I used the Figma plug-in 'Specs' to generate initial spec pages, then manually made necessary edits

SPEC LAYOUT:

→ Anatomy

→ Properties

→ Theme

→ Layout and spacing

SPECS TAKEAWAYS:

📌 Charlotte (our front-end developer) said that having all of the different variations and specific spacing was extremely helpful

📌 For design work in my clubs, developers have mentioned wanting more documentation: now I know how to give them that

📌 Although components seem simple, there are a lot of elements and specific usage cases for them
